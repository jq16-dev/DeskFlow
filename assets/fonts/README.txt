DeskFlow Custom Fonts
=====================

Place .ttf or .otf font files in this folder.
DeskFlow loads them automatically at startup via QFontDatabase.

Recommended free fonts:
  Inter       → https://fonts.google.com/specimen/Inter
  Roboto      → https://fonts.google.com/specimen/Roboto
  JetBrains Mono → https://www.jetbrains.com/lp/mono/
  Nunito      → https://fonts.google.com/specimen/Nunito
  Outfit      → https://fonts.google.com/specimen/Outfit

After placing fonts here, restart DeskFlow.
Then select them in the element editor → Font Family picker.

Built-in system fonts (always available):
  Segoe UI, Arial, Calibri, Consolas, Courier New,
  Georgia, Tahoma, Trebuchet MS, Verdana
